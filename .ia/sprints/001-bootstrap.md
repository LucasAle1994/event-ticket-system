# Sprint 001 - Project Bootstrap

## Goal

Bootstrap the project following the architecture defined in:

- docs/PROJECT.md
- docs/DECISIONS.md
- docs/TASKS.md
- docs/AGENTS.md

This sprint only prepares the project.

No business logic should be implemented.

---

# Objectives

- Create the Next.js project.
- Configure the development environment.
- Install all required dependencies.
- Configure Prisma.
- Configure PostgreSQL.
- Configure TailwindCSS.
- Configure shadcn/ui.
- Configure ESLint.
- Configure Prettier.
- Configure import aliases.

---

# Folder Structure

The following folders must exist.

app/

components/

features/

lib/

prisma/

public/

types/

docs/

.ai/

---

# Dependencies

Required:

- Prisma
- @prisma/client
- PostgreSQL
- React Hook Form
- Zod
- shadcn/ui

Do not install unnecessary libraries.

---

# Out of Scope

Do NOT create:

- Pages
- Components
- Business logic
- Database models
- Services
- UI

---

# Acceptance Criteria

The project must:

- compile successfully
- build successfully
- lint successfully

No TypeScript errors.

---

# Deliverables

- Project created
- Dependencies installed
- Folder structure ready
- Prisma configured
- PostgreSQL configured
- shadcn configured

---

# Definition of Done

- [ ] npm install
- [ ] npm run dev
- [ ] npm run lint
- [ ] npm run build

All commands must execute successfully.
